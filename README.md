# Telamon

An optional, Jarvis-like voice assistant for Telamon OS. Say "Hey Telamon,
what's the weather like?" and it answers out loud, with a gold glow around the
screen that follows the voices.

It is off until you allow the microphone, runs entirely on this computer
(openWakeWord, Silero VAD, whisper.cpp, llama.cpp, Kokoro), and its tools only
read: system stats, processes, network, time, files, weather.

See `docs/DESIGN.md`.
